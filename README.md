# Summary
Системный аналитик с 3 годами опыта в разработке мобильных, web- и enterprise-систем. Работаю с полным циклом системного анализа — от сбора и формализации требований до проектирования API и интеграций, декомпозиции, сопровождения разработки и приёмки решения. 
Проектирую REST API, синхронные и асинхронные взаимодействия, модели данных и интеграционные сценарии. Работал с микросервисной и event-driven архитектурой, мобильными приложениями Android/iOS, Telegram Mini Apps и промышленными системами на CAN-шине.
